## Generating Alternative Interpretations of a Predication
Imagine we'd like to add a few special places to the system like "home" or "trash" so the user could say "go to home" or "go to trash" and have the system go to a hard-wired place. "home" might mean this special hard wired place, but it also might mean a folder that happens to be called "home" that is in the current directory.
